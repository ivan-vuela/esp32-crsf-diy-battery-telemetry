# ESP32 CRSF DIY Battery Telemetry

This repository contains sample code used for a DIY project that shows how to integrate an ESP32 with and ELRS receiver
and a voltage divider, to send battery voltage telemetry over ELRS.

[Video of everything working together](https://www.instagram.com/reel/DevEF8gRAgt/)

## Dependencies

- https://github.com/AlfredoSystems/AlfredoCRSF

## Components
This is a list of electronic components used for the demo video, but it should work with other compatible components.

* ESP32-S3
* 2.4GHz ELRS Receiver
* Voltage divider/sensor
* Radiomaster Boxer 2.4GHz ELRS Transmitter
* ToolkitRC M7 battery balancer (also works with an ESC)
* LiPo battery
